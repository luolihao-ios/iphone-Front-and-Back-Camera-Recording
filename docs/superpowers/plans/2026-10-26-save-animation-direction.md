# 1.0.13 (4) 相册吸入动效方向修正

## 排查依据

相册按钮只在未录制时出现。录制时偏好值恢复默认零矩形，旧代码直接覆盖相册位置；保存时按钮重新出现，测量结果与启动动画不同步，存在动画目标先指向原点、随后改变的竞态。

原遮罩在结束时 topY=高度×0.48、bottomY=高度×0.45，上边缘越过下边缘，会产生翻折。上述为源码可复现的问题，具体真机表现还需测试确认。

## 修正

- 仅接收有效的相册位置，隐藏按钮时保留最近一次有效位置。
- 动效开始时锁定目标；之后的布局测量不改变当前动效轨迹。
- 将命名坐标系中的相册位置转换到动效覆盖层的本地坐标，避免安全区和容器原点偏移。
- 图片最终收进相册按钮内，漏斗保持下窄上宽，不再交叉翻折。
- 无有效目标时只更新缩略图，不向屏幕原点播放错误动效。
- 本地诊断日志记录目标矩形、覆盖层原点及换算后的终点；不记录图像内容。

## 验证

新增六项回归测试：按钮隐藏、动效中重新布局、缺少目标、向左下单调移动及终点包含、坐标原点转换、全程遮罩不交叉。运行现有完整测试套件。

Windows 本地无 Xcode；本轮 iOS 构建与测试结果待远端确认，不将静态检查等同于真机效果验证。
